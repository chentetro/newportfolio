Add Contact Button to SocialButtons Component
Overview
Add a Contact button with mailto link functionality to the SocialButtons component. The Contact button will use the exact same styling as the GitHub button (gray/black colors) and the email prop will be added to the TypeScript interface.

Implementation Steps
1. Update TypeScript Interface
File: app/components/SocialButtons.tsx
Add email: string to the SocialButtonsProps interface
Add email to the destructured props in the component function parameters
2. Add Contact Button
File: app/components/SocialButtons.tsx
Insert Contact button after the CV button
Include email/envelope SVG icon
Use mailto link: href={mailto:${email}}
Apply exact same styling as GitHub button:
Base classes: flex items-center gap-2 px-4 py-2 bg-gray-900 dark:bg-gray-100 text-white dark:text-gray-900 rounded-lg
Hover: hover:bg-gray-800 dark:hover:bg-gray-200
Transitions: transition-colors duration-200 font-medium
Include accessibility attribute: aria-label="Contact via email"
Note: Do not include target="_blank" or rel attributes for mailto links (not needed)
3. Verify Implementation
Check that email prop is added to interface
Verify Contact button displays with email icon
Confirm Contact button uses exact same Tailwind classes as GitHub button
Test that mailto link opens email client when clicked
Verify dark mode support matches GitHub button styling
